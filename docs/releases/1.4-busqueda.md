# Búsqueda global de películas

- La lupa de **Para vos** abre una pantalla dedicada.
- Busca por título en todo el catálogo, sin aplicar géneros ni plataformas de Preferencias.
- Muestra póster, año, puntuación y disponibilidad argentina cuando existe.
- **La vi** abre el mismo flujo de puntuación y reseña que las recomendaciones.
- Una película registrada desde la búsqueda alimenta el historial y la gamificación habitual.

Requiere desplegar primero el backend que expone `GET /api/peliculas/buscar`.
