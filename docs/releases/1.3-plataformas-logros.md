# Plataformas e insignias

- Para vos muestra una etiqueta compacta con la primera plataforma seleccionada disponible en Argentina y `+N` cuando hay más. La fuente se atribuye a JustWatch.
- Si la disponibilidad no llega, el reel conserva el título y la puntuación sin mostrar un aviso ni inventar una plataforma.
- El salón usa recursos propios y livianos: balde de cartón texturado, pochoclos realistas y animación nativa.
- Las insignias viven en un estante. Las bloqueadas quedan atenuadas; las conseguidas se muestran a color.
- Primera colección: Game of Thrones (8 temporadas), Breaking Bad (5) y Dark (3). El backend calcula el logro desde las temporadas guardadas; desmarcarlas actualiza el estante.
- Las imágenes son diseños originales y no reutilizan logos, personajes ni arte oficial.

Compatibilidad: el frontend oculta etiquetas e insignias si todavía responde el backend anterior. No agrega dependencias nativas. Requiere desplegar el backend nuevo para recibir `plataformas` e `insignias`.

Verificación: TypeScript, `scripts/test-providers-achievements.cjs`, pruebas enfocadas del backend y exportación JavaScript Android. La apariencia final debe comprobarse en el teléfono antes del próximo APK.
